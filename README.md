# Worky-2.5

Воркометр 2.5

Приложение-счетчик для отслеживания суточного и общего времени затраченного на что-то(обучение, чтение, игры итд)
Приложение считает время в скиллах один скилл равняется 100 секундам, 100 скиллов равняется примерно 166 минутам или 2 часа 46 минут

Возможности:
-Запуск/остановка счетчика
-суточный и общий счетчик
-Сохранение в SQLite 
-Основная и резервная запись в базе данных
-Возможность резервного восстановления прогресса в случае повреждения основной записи. Сохранение резервной копии происходит каждый раз при нажатии кнопки стоп.

Установка
python3 -m venv .venv
source .venv/bin/activate
pip install pillow

Запуск
bash
python3 main_menu.py
либо с иконки worky.command

Структура:
-main_menu.py - основной запуск
-display.py - интерфейс и логика приложения
-data_base.py - база данных
-function.py - вспомогательные функции
-settup_aplication.py - настройка имени и резервное восстановление
